# PCB Maker（PCB制作大师）

一句话：这是一群会画电路板的 AI 智能体的"学校"——它们上课、考试、被打分，一代一代变强。

## 这里有什么

**学生**：一个 PCB 设计智能体家族。一个总调度（PCB-Orchestrator）负责接单，把"给我画一块能制造的板子"拆开，派给画原理图、摆放、布线、铺铜、质检等专职角色。它们的产出是真实的 KiCad 工程文件，最后要过 DRC/ERC 这类硬件规矩检查。

**考卷和尺子**：光有学生不行，还得有公平的考试。本仓库放了考题（从元件清单到一块小板子的完整流程，分成几个阶段）和一台独立评分器——评分器不信学生自报成绩，它自己重新跑 KiCad 复测：错误数、悬空线、埋没在板子里的坑有没有被诚实记录。

**进化账本**：每一轮谁出题、谁答了、答了多少分、尺子自己哪里坏了、怎么修的，全部记在一本只能追加、不能涂改的流水账里。考试作弊的定义包括"改了旧账页"。

## 现在的真实水平

第一次正式基线考试：**0.521 分（及格线 0.70，未过）**。

- 好的地方：摆放布局零硬错误；在 10KB 的答题笔记里诚实记录了踩到的坑，包括主动指出考题本身印刷错误；不越权、不硬编数据。
- 差的地方：布线收不了尾、原理图电气检查没闭环、时间管理弱（在细节探索上花掉了预算）。

这些短板就是接下来每一代要进化的方向。智能体的任何"大脑升级"，必须先在考试里证明自己比旧版本强，最后要不要采纳，决定权始终在人手里。

## 目录

- `agents/` —— 智能体家族的角色说明（谁负责什么、遵守什么纪律）
- `scenarios/` —— 考卷
- `graders/` —— 评分器和考场搭建脚本
- `ledger/` —— 进化流水账（append-only）
- `evidence/` —— 每轮考试的原始工件（答题笔记、成绩单、事故报告）

先读 `ledger/` 里最近十行——所有故事都从那本账里长出来。
